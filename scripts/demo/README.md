# Madang 데모

앱에서 한 동작 흐름을 직접 확인하는 프로젝트 세 개다. 프로젝트마다 페이지가 두 개 있다.

| 폴더 | 종류 | 실행 완료 페이지(이미 한 번 돌린 결과) | 요청 대기 페이지(여기서 보낸다) |
|---|---|---|---|
| `wiki/` | 위키 노트(git 아님), `site/`로 자동 게시 | 도구 노트 보강 | 가을 준비 노트 |
| `code/` | 파이썬 코드(git), 테스트 통과 시 자동 머지 | 합계 함수 설명 | 할인 계산 버그 |
| `resume/` | 이력서 문서(git 아님), 프로젝트 전용 뷰어 `resume/basic` | 자기소개 다듬기 | 이력서 직함 바꾸기 |

## 준비

1. `Madang.app`을 설치하고 한 번 연다(온보딩: 앱 홈 초기화 → claude 로그인 확인).
2. 왼쪽 위 **+ 프로젝트**로 `wiki`, `code`, `resume` 폴더를 하나씩 추가한다. 추가만 하면 각 프로젝트에 페이지 두 개가 보인다.
3. 실행 완료 페이지를 열어 본다. 가운데 **문서** 탭에 요청·결과 블록이, 오른쪽 **메모리** 탭에 Profile·Brief·Ledger가, **기록** 탭에 실행(모델·결과·비용)이 있다.

## 데모 시나리오

각 단계는 요청 대기 페이지를 왼쪽에서 고르고, 아래 문장을 입력창에 붙여 **보내기**를 누른다.

**1. 위키 요청 → 게시 반영** (`wiki` › 가을 준비 노트)

> notes/garden.md 노트 끝에 '## 가을 준비' 절을 새로 추가하고, 그 절에 '마늘은 10월에 심는다.' 한 줄을 넣어 줘. 다른 파일은 고치지 않는다.

- 볼 곳: 오른쪽 **지금**(진행), 끝나면 결과 블록의 게시 상태. 오른쪽 **파일**에서 `위키 사이트`(실행 배지)를 더블클릭하면 가운데 **브라우저** 탭에 `http://localhost:8710`이 열린다.
- 기대: `notes/garden.md`에 새 절, `site/notes/garden.html`에도 같은 절. 사람에게 묻지 않고 게시까지 끝난다.

**2. 코드 버그 수정 → 테스트 → 자동 머지** (`code` › 할인 계산 버그)

> receipt.py의 apply_discount가 10% 할인에 0원을 돌려준다. 버그를 고쳐 모든 테스트가 통과하게 해 줘. 테스트 파일은 고치지 않는다.

- 볼 곳: 가운데 **디프** 탭, 오른쪽 **git** 탭(브랜치·워크트리·로그), 결과 블록의 머지 상태.
- 기대: 실행 중에는 `madang-demo/code.wt/<페이지>/` 워크트리에서 고치고, `python3 -m unittest -q`가 통과하면 `main`에 머지 커밋이 생긴다(머지 뒤 워크트리는 정리된다). 테스트가 실패하면 머지하지 않고 페이지에 묻는 블록이 생긴다.

**3. 이력서 JSON 수정 → 문서 탭 = 게시 화면** (`resume` › 이력서 직함 바꾸기)

> docs/resume.json에서 title을 '결제 플랫폼 리드 엔지니어'로 바꾸고, 바다페이 경력의 highlights 맨 앞에 '정산 대사 자동화' 항목을 넣어 줘. 다른 파일은 고치지 않는다.

- 볼 곳: 오른쪽 **파일**에서 `docs/resume.md`를 열면 가운데 **문서** 탭, `docs/resume.json`은 **데이터** 탭. `site/docs/resume.html`은 **브라우저** 탭.
- 기대: 문서 탭과 게시 화면에 같은 직함과 새 항목이 같은 모양으로 보인다(같은 렌더러, 게시본은 뷰어 사본을 함께 담는다).

**4. 앱 재시작 뒤 기록 유지**

- 앱을 끝내고 다시 연다. 세 프로젝트의 페이지, 문서 탭의 요청·결과 블록, **메모리** 탭의 Ledger, **기록** 탭의 실행이 그대로다. 기록은 모두 각 폴더의 `.madang/`에 있다.

**5. 되돌리기** (`code` › 할인 계산 버그)

- 2단계 결과 블록의 **되돌리기**를 누른다.
- 기대: **git** 탭 로그에 `Revert "Merge branch ..."` 커밋이 생기고 `receipt.py`가 원래대로 돌아가며 테스트가 다시 1개 실패한다. 머지 커밋은 이력에 남는다. 1·3단계의 게시도 같은 방식으로 되돌린다.

## 문제가 생기면

- 실행 원본 로그: `<프로젝트>/.madang/pages/<페이지>/runs/<n>.jsonl`, 실행 기록 `runs/<n>.json`, 되돌리기 기록 `runs/<n>.undo.json`.
- 페이지 본문과 기억: 같은 폴더의 `page.md`, `ledger.md`. 프로젝트 설정은 `<프로젝트>/.madang/config.yaml`.
- core 출력: 터미널에서 `<경로>/Madang.app/Contents/MacOS/Madang`으로 앱을 띄우면 그 터미널에 나온다. 앱 설정은 `~/Library/Application Support/Madang`, 앱 홈은 `~/.madang/`.
- 흐름이 "쓸 수 있는 실행기가 없어" 멈추면 터미널에서 `claude auth status`로 로그인을 확인한다.

## 다시 만들기

저장소에서 `bash scripts/demo/make-demo.sh`. 이 폴더가 있으면 지우지 않고 `madang-demo.bak-<시각>`으로 옮긴 뒤 새로 만든다. 실행 완료 페이지는 임시 앱 홈으로 claude에 실제 요청을 한 번씩 보내 만든다.
