# Madang: 비전

상태: 초안 (AI 작성, 미승인)
작성: 2026-09-24

## 한 문장

**AI 코딩 에이전트와 함께 일하는 사람을 위한, 문서·화면·실행이 한 페이지에 있는 작업 공간.**

마당(Madang)은 일이 벌어지는 열린 공간이다. 대화, 살아 있는 화면, 데이터, 실행 중인 프로세스가 한 마당에 모이고, 완성된 것은 그대로 밖으로 나간다.

## 왜 만드는가

지금은 네 가지 도구를 따로 쓴다.

| 하는 일 | 지금 쓰는 도구 | 불편한 점 |
|---|---|---|
| 에이전트에게 시킨다 | Claude Code, Codex | 매번 도구와 모델을 고른다. 세션이 커질수록 비싸진다. 무엇을 읽고 있는지 안 보인다 |
| 결과를 본다 | 브라우저, 터미널 | 채팅과 분리되어 맥락이 끊긴다 |
| 결정과 맥락을 적는다 | 노션, 옵시디언 | 에이전트가 읽지 않는다. AI가 만든 파일이 어디에 있는지 모른다 |
| 완성물을 내보낸다 | Vercel, GitHub Pages | 문서와 배포가 별개 작업이다 |

Madang은 이 넷을 하나의 "페이지" 안에 넣는다.

## 되고 싶은 것

1. **중립 작업대.** Claude와 Codex 중 무엇이 일했는지가 페이지에 남고, 다음 일을 누구에게 줄지는 규칙이 정한다. 어느 모델 회사도 상대 회사 모델로 보내 주지 않는다. 그 빈자리가 Madang의 자리다.
2. **보이는 메모리.** 에이전트가 매 호출 무엇을 읽는지가 파일로 있고, 사람이 그 파일을 고친다. 세션은 버리고 파일만 이어진다. 매 호출 입력 크기가 화면에 보인다.
3. **살아 있는 문서.** 문서 안의 화면은 데이터에 연결되어 있고, 데이터가 바뀌면 화면이 바뀐다. 표현은 템플릿이, 내용은 데이터가, 판단은 AI가 맡는다.
4. **배포되는 문서.** 페이지 하나를 골라 내 도메인으로 내보낸다. 블로그, 랜딩 페이지, 위키, 대시보드가 같은 방식으로 만들어진다.

## 되지 않을 것

- **코드 편집기가 아니다.** 코드는 에이전트가 쓰고, Madang은 결과와 차이를 보여준다. 직접 고치고 싶으면 외부 편집기로 연다.
- **모델 API 중계업이 아니다.** 로컬에서는 사용자 본인의 구독 CLI를, 서비스에서는 운영자 API 키와 사용자별 크레딧을 쓴다. 가치는 모델 접근이 아니라 작업 방식에 있다.
- **범용 노트 앱이 아니다.** 모든 페이지는 "무언가를 만들고 있는 작업"이다.

## 설계 원칙 7가지

이후의 모든 결정은 이 일곱 개로 환원된다. 새 기능이 하나라도 어기면 넣지 않는다.

1. **페이지 폴더가 진실이다.** 화면의 모든 것은 디스크 파일을 그린 결과다. 삭제는 파일 삭제, 복구는 git.
2. **모든 것은 블록이다.** 메시지, 화면, 데이터, 터미널, 코드가 같은 단위이며 같은 방식으로 확대·연결·삭제된다.
3. **트리는 하나다.** 탐색은 공간 → 페이지 → 블록 하나뿐. 코드 저장소의 파일 트리는 블록 안에서만 보인다.
4. **입력창은 항상 "지금 보고 있는 것"에게 말한다.** 페이지, 블록, 요소. 입력창은 하나이고 대상만 바뀐다.
5. **AI는 데이터를 쓰고, 표현은 템플릿이 한다.** AI가 HTML을 매번 만들지 않는다.
6. **세션은 버리고 파일은 잇는다.** 에이전트 호출은 매번 새 세션. 이어지는 것은 페이지 폴더의 문서뿐.
7. **부작용은 앱 명령을 통해서만.** 커밋, 푸시, 삭제, 승격, 배포는 에이전트가 직접 하지 않고 `madang` 명령으로 요청한다. 위험 판단은 모델이 아니라 앱 코드에 있다.

## 첫 목표 (Phase A)

다음 넷이 한 번에 돌아가는 것.

1. 빌드된 앱을 띄운다 (macOS, Windows).
2. 레이어 0(3열: 공간 / 페이지 목록 / 페이지 본문)에서 대화한다.
3. 대화가 정해진 흐름(라우터 → 실행 → 검사 → 판정 → 커밋)을 타고, 에이전트는 매번 새 세션으로 state.md만 읽고 이어간다.
4. 페이지 안의 뷰 블록(빌드된 HTML)을 확대해 조작하고, 편집 모드에서 요소를 골라 대화로 고친다.

이 넷이 되면 사용자는 터미널에서 `claude`나 `codex`를 직접 열 이유가 없어진다. 그것이 Phase A의 완료 기준이다.
