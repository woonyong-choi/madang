# Madang 로드맵 (조각 단위)

상태: 초안 (AI 작성, 미승인). 2026-09-24 전면 개정. 이전 Phase A~F 표는 git 이력에 있다.

원칙: 조각 하나 = 사용자가 일주일 써 볼 수 있는 앱. 조각이 끝나면 멈추고 써 본 뒤 다음을 정한다.

## 조각 1. 보이는 실행 (v0.1)  ← 지금
사용자가 페이지를 만들고 요청을 보내면 Claude가 새 세션으로 돌고, 결과·결정·읽은 파일이 페이지에 남는다.
- 저장: `<project>/.madang/` (D23). 앱 홈·승격 제거.
- 화면: 왼쪽 프로젝트→페이지, 가운데 탭(페이지·term), 오른쪽 사이드바 탭 지금·메모리·기록 (D24).
- 실행: routes.yaml, 승격, 대체(codex 배제 상태), state.md 검사기, 진행 로그.
- 지금 탭: 진행 중 실행, 상태 글리프, 미읽음 굵게, 알림, 재시작 칩, 사용량 막대(~/.claude 파서, Orca 이식).
- 배포: macOS dmg(PyInstaller core 동봉). 설치 3줄, 체크리스트.
- 과업: WP-07·08·12·25·26·27·28 + WP-29(저장 구조 D23 전환, 패키징 전).
- 끝: 일주일 dogfood. 멈춤.

## 조각 2. 읽는 리뷰
코드 페이지에서 디프를 읽고 줄에 댓글을 달면 그것이 다음 프롬프트가 된다.
- code 탭, 디프 주석(Orca 로직 이식), 커밋·PR 생성, 파일 탭, 산출물 탭.
- PTY 데몬과 xterm 구성(Orca 이식), 세션 복원.
- Jump 팔레트(Orca 순위 규칙).

## 조각 3. 살아 있는 이력서
비코딩 페이지에서 템플릿+JSON으로 뷰가 그려지고, 에이전트는 데이터만 바꾼다.
- view 블록, 프리셋, data-bind, 뷰에서 요소 지정 → 프롬프트(Orca design-mode 주입 JS 이식).
- MCP Apps 호환 검토(P1), 스키마 카탈로그(P3).
- Jev식 결정 타입.

## 조각 4. 밖으로
- site 탭(브라우저 프로필·뷰포트, Orca 이식), 포트 탭, 내 도메인 게시.
- Windows 빌드. GitHub 이슈→페이지.
- codex 재허용 시 양방향 대체 재검증.

## 이후 (미정)
- 원격(`serve` 프로토콜, 페어링) → Android·iOS.
- 서비스 부분(Phase F 구상)은 별도 저장소.
