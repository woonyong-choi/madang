# Madang 로드맵 (v2)

상태: 초안 (AI 작성). 2026-09-24 v2 스펙(10-spec-v2.md) 기준으로 전면 개정.

원칙: 조각 하나 = 사용자가 매일 쓸 수 있는 앱. 조각이 끝나면 멈추고 써 본 뒤 다음을 정한다. 각 조각의 "끝" 판정은 체크리스트로 한다.

## 조각 1. 한 동작 (v0.1)
페이지에 요청을 보내면 결과가 페이지에 남고, 코드는 정책대로 머지되고, 문서는 게시된다. 버튼은 보내기 하나.
- 저장·기억·설정: §2 레이아웃, Profile/Brief/Ledger 이름, config.yaml.
- core: recorder, git, policy, publish(gh-pages·폴더), runs(선언·실행·포트 관찰), viewers(등록부·live·pinned·스키마·격리 명세), api 확장.
- 앱: 여섯 탭(디프·데이터·브라우저 포함, 터미널·채팅은 v0.2), 오른쪽 지금·파일·메모리·git·포트·기록, 보내기 한 동작, 묻는 블록, 되돌리기.
- 렌더러: 앱 문서 탭 = publish 렌더러. ```view``` 펜스, iframe 격리, 토큰 주입.
- 배포: macOS dmg(PyInstaller core 동봉). 설치 3줄. 체크리스트 통과.
- 끝 판정 체크리스트: (1) 위키 노트 하나에 요청 → 게시 웹에 반영, (2) 코드 프로젝트에 버그 수정 요청 → 테스트 통과 → 자동 머지 → 페이지에 기록, (3) 이력서 JSON 수정 → 문서 탭과 게시 웹이 같은 화면, (4) 앱 재시작 후 세 페이지 기록이 그대로, (5) 되돌리기로 (2)를 되감음.

## 조각 2. 안에서 다 한다 (v0.2)
