이 화면에서 볼 것

  1. 가운데 채팅의 회색 점선 줄이 라우터의 결정입니다. 분류, 확신도, 선택한 도구·모델, 승격 이유가 매 턴 남습니다.
  2. 메모리 탭 아래 표가 다음 호출에 실제로 들어갈 입력입니다. 채팅이 길어져도 합계가 거의 변하지 않는 것이 이 구조의 핵심입니다.
  3. 산출물 탭의 노란 상자가 찌꺼기 감지입니다. 앱이 git으로 새 파일을 찾고, 등록 안 된 것만 올립니다.
  4. 결정 보드와 일정은 state.md 위쪽 데이터에서 앱이 그린 것이라, AI가 그림을 그리는 데 토큰을 쓰지 않습니다.
