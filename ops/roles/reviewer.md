대상: {WP}  (브랜치 {BRANCH}, 빌더 보고 ops/reports/{WP}.md)
명세: ops/tasks/{WP}.md

할 일
1. 명세와 관련 docs/ai/ 절을 읽는다.
2. `git diff main...{BRANCH}`를 읽는다. 명세 범위 밖 변경이 있으면 지적한다.
3. 검증 명령을 직접 다시 실행한다. 빌더 보고의 결과와 다르면 지적한다.
4. 설계 문서와의 충돌, 원칙 7가지 위반, 테스트 누락, 하드코딩된 경로·비밀, AI 흔적이 남은 커밋을 찾는다.
5. `ops/reports/{WP}-R.md`에 아래 양식으로 쓴다.

```
# {WP} 리뷰
```
